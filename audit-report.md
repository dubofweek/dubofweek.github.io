## index.html

### 🔴 Критично

| # | Строка | Проблема | Описание |
|---|--------|----------|----------|
| 1 | 831, 1398, 1419 | **Нет `<h1>` на странице** | Все заголовки — `<h3>`. `<h1>` отсутствует полностью. SEO-провал для главной страницы. |
| 2 | ~159–308 | **Дублирование категорий в мобильном меню** | Весь список категорий внутри мобильного меню повторяется дважды — явный copy-paste баг. |
| 3 | 1854 | **Неверное название сайта в дисклеймере** | Написано `Sex Ocean has a zero-tolerance policy...` — должно быть `Porn Ocean`. |

### 🟡 Важно

| # | Строка | Проблема | Описание |
|---|--------|----------|----------|
| 4 | 21 | **`<meta name="rating" content="">` пустое** | Для adult-сайта стандартное значение: `content="RTA-5042-1996-1400-1577-RTA"`. Без него сайт не будет правильно фильтроваться. |
| 5 | 6 | **`user-scalable=no` в viewport** | `maximum-scale=1, user-scalable=no` блокирует зум на мобильных. Нарушение WCAG 1.4.4. |
| 6 | 1070–1249 | **Плейсхолдерные данные в видео 9–15** | Все 7 карточек имеют одинаковые `alt`, просмотры `1.3K` и длительность `9:40`. Заглушки не заменены. |
| 7 | 428 | **Невалидный инлайн-стиль в SVG** | `<path style="#fff">` — `style` принимает CSS-свойства, а не цвет напрямую. Должно быть `style="fill:#fff"` или убрать (атрибут `fill` уже есть на родительском `<svg>`). |
| 8 | 39–44, 100–106 | **Поисковые поля без `<form>`** | `<input>` + `<button>` не обёрнуты в `<form action>`. При отключённом JS поиск не работает. |

## index.html — UX/UI

> Анализ на основе HTML-структуры и CSS (style.css, main.css, menu.css, footer.css).
> Дизайн-система: тёмный фон `#060510`, акцент синий `#5272FB`, шрифт Inter.

### 🔴 Критично

| # | Файл / Строка | Проблема | Описание |
|---|--------------|----------|----------|
| U1 | menu.css:9–16 | **`text-shadow` на логотип-изображение не работает** | Neon glow написан на `.logo` через `text-shadow`, но логотип — это `<img>`. `text-shadow` к изображениям не применяется. Эффект не виден. Нужно заменить на `filter: drop-shadow(...)`. |
| U2 | menu.css:141 | **Сломанная CSS-переменная у кнопки Sign Up** | `color: var(color-white)` — пропущены дефисы. Должно быть `var(--color-white)`. Цвет текста кнопки не применяется. |

### 🟡 Важно

| # | Файл / Строка | Проблема | Описание |
|---|--------------|----------|----------|
| U3 | index.html:874+ | **Видео-карточки не обёрнуты в `<a>`** | `<div class="video-card">` вместо `<a href="...">`. Нельзя открыть видео в новой вкладке, нет SEO-ценности ссылки. |
| U4 | main.css:60–65 | **Нет hover-эффекта на видео-карточках** | `.video-card` имеет `cursor: pointer`, но нет `:hover` (scale, overlay, подсветка). Пользователь не получает обратную связь что карточка кликабельна. |
| U5 | menu.css:136–148 | **Нет hover-состояния на кнопках Sign Up и Login** | В CSS нет `.btn-signup:hover` и `.btn-login:hover`. Кнопки выглядят статично и не реагируют на наведение. |
| U6 | main.css:219–232 | **Тег-ссылки без hover-состояния** | `.tag-item` имеет `transition: color 0.2s, border-color 0.2s`, но нет `:hover` правила. Анимация есть, а триггера нет — пустая трата. |
| U7 | main.css:154–175 | **Кнопки пагинации — `<button>` вместо `<a>`** | Пагинация на `<button>` — нельзя открыть страницу в новой вкладке, нет URL в строке браузера. Должно быть `<a href="/page/2">`. |
| U8 | main.css:636–650 | **2 колонки на экранах меньше 400px** | На экранах 320–400px карточки будут ~150×85px — слишком мелко. Стоит добавить breakpoint `max-width: 400px` → 1 колонка. |

### 🟢 Рекомендации

| # | Файл / Строка | Проблема | Описание |
|---|--------------|----------|----------|
| U9 | menu.css:302–326 | **Toggle-переключатели без визуального состояния `:checked`** | `.toggle__slider::before` пустой, нет правила `input:checked + .toggle__slider`. Пользователь не видит включён тогл или нет. |
| U10 | index.html:831 | **Дата в заголовке секции — `<h3>` вместо `<time>`** | `FRIDAY, 30 January, 2026` семантически должен быть тег `<time datetime="2026-01-30">`. |
| U11 | index.html:39–44 | **Поиск — иконка только кнопка справа** | Нет иконки-лупы слева внутри поля. Стандартный UX-паттерн для поиска — иконка слева в инпуте. |
| U12 | style.css:191–192 | **Баг в утилитарном классе `.pad-left-0`** | Класс называется `pad-left-0`, но внутри написано `padding-right: 0` вместо `padding-left: 0`. |
| U13 | index.html:1918–1919 | **Privacy-логотипы без размеров** | `<img src="privacy_1.jpg">` без `width`/`height` — вызывают CLS (сдвиг контента при загрузке). |
| U14 | — | **Нет состояния загрузки / скелетонов для карточек** | При медленном соединении grid-сетка появляется с задержкой. Скелетон-заглушки улучшили бы воспринимаемую скорость загрузки. |
| U15 | — | **Нет кнопки "Наверх"** | Страница длинная (видео + категории + pornstars + футер). Кнопка scroll-to-top — стандарт для подобных сайтов. |
